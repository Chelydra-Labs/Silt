## Write in the page editor

Open a page from the sidebar. The main pane is a block editor: headings,
tasks, notes, code, callouts, and tables are first-class blocks that still
save as plain markdown.

## Slash menu (`/`)

Type **`/`** to open the command palette in the editor. Use it to insert
tables, headings, tasks, callouts, code, templates, and more. See the
**Slash commands** help topic for the full built-in list, including **Table**
and **Custom table…**.

## Format toolbar

When the caret is in the editor, a formatting toolbar offers bold/italic and
an **Insert** menu (table, and other inserts depending on build). Toggle the
toolbar with its hotkey (default **Ctrl+F1** — check **Keyboard shortcuts**).

## Tasks and checkboxes

Create a task with slash **Task**, or type a GFM checkbox line
(`- [ ] …`). Task metadata (due, owner, tags) uses inline tokens on the line.
The Tasks hub lists tasks across the vault.

## Source view

You can switch to markdown **source view** for the page when you want raw
text. Tables appear as pipe syntax there.
