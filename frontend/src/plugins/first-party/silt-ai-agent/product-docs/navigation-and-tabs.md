## Browse notebooks

The left sidebar is **Notebook › Section › Page**. The activity bar **Notes**
view is the normal editor shell. Other activity items (for example **Tasks**,
**Backlinks**, **Tags**) change the main surface.

## Preview vs pinned tabs

- **Single-click** a page → opens a **preview** tab (often shown italic).  
- **Double-click** → opens a **pinned** tab.  
- Promote a preview: middle-click, start editing, or tab menu **Pin Tab**.

Empty-state guidance: “Single-click opens a preview; double-click opens a
pinned tab.”

## Tab strip

Open pages appear as tabs above the editor. Tabs are **per notebook** —
switching notebooks shows that notebook’s tab set.

- Close tab: default **Ctrl+Shift+W** (check **Keyboard shortcuts**).  
- Only **pinned** tabs restore after restart; previews are session-only.  
- Optional dirty/saving indicators depend on settings.

## Create structure

Typical defaults (remappable under Settings → Hotkeys):

| Action | Default |
| --- | --- |
| New page | Ctrl+N |
| New section | Ctrl+Alt+N |
| New notebook | Ctrl+Alt+Shift+N |

## Cross-notebook jumps

Search, wiki links, and backlinks can switch the active notebook and its tabs
when the target lives elsewhere (including linked notebooks).
