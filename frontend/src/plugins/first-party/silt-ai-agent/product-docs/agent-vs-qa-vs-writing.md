## AI Agent

The **agent** is a multi-step assistant with tools: search and read notes,
query tasks, create or update content (when writes are allowed), and answer
how-to questions about Silt from shipped product help. It can also answer
general questions without using the vault.

## Vault Q&A (AI Assistant)

**Q&A** answers only from **your vault excerpts** with citations. It does not
run agent tools, does not write notes, and does not load product help as a
source. Use it when you want answers grounded strictly in your notes.

## Writing Assistant

**Writing** offers curated rewrite/expand-style actions. Results appear as
accept/discard proposals — nothing is applied until you accept.

## Which should I use?

| Goal | Use |
| --- | --- |
| How do I use Silt / set up AI? | Agent (product help) |
| What did I write about X in my notes? | Q&A or Agent with vault search |
| Rewrite this paragraph | Writing Assistant |
| Create a note or rename a tag | Agent (with write policy) |
