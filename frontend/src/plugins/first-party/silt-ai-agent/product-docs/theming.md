## Theme and mode

Open **Settings** and use the appearance / theme controls to pick an active
theme and light, dark, or system mode. Theme choice can apply before a vault
is open (user-global preference).

## Built-in vs custom themes

Silt ships built-in themes. You can also install or author custom themes that
live with the vault under `.system/themes/`. Typography and related overrides
may be stored per vault in config.

## Tips

- Switch themes anytime; the UI updates without restarting.
- Vault export includes `.system/` themes so appearance travels with backups.
- Prefer theme packages over one-off CSS hacks so updates stay portable.
