## Tasks in notes

Task lines are GFM checkboxes in your markdown (for example `- [ ]`). Status,
due dates, owners, and other fields use inline metadata tokens on the task
line. The Tasks hub lists and filters tasks across the vault.

## Standalone tasks

Quick-add surfaces can create tasks that are not attached to a normal note;
those live in a system tasks file and still show in the Tasks hub.

## Tags

Use `#hashtags` on blocks for organization. The agent can list tags, find
untagged tasks, and (with confirmation) rename a tag across the vault.

## Agent help with tasks

With AI enabled, ask the agent to query overdue tasks, create a task, or
update status — subject to **Agent vault writes** (confirm/auto/read only).
