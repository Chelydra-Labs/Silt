## Tasks in notes

Task lines are GFM checkboxes in your markdown (for example `- [ ]`). Status,
due dates, owners, and other fields use inline metadata tokens on the task
line. Convert a block with slash **Task**, or create tasks from the **Tasks**
hub.

## Tasks hub

Open **Tasks** on the activity bar for **List**, **Board**, and **Calendar**
views, smart lists, and saved views. See the **Tasks hub** help topic for
modes, quick-add (**Ctrl+Shift+N**), and standalone tasks.

## Standalone tasks

Quick-add can create tasks that are not attached to a normal note. They live
in a hidden system file and only appear in the Tasks hub (not as a regular
sidebar page).

## Tags

Use `#hashtags` on blocks or set tags in **page properties**. The same tag
system powers filters in Search vault and the Tasks hub. With AI on, the agent
can list tags, find untagged tasks, and (with confirmation) rename a tag
across the vault.

## Agent help with tasks

Ask the agent to query overdue tasks, create a task, or update status —
subject to **Agent vault writes** (confirm / auto / read only).
