## Shortcut cheatsheet

Silt includes an in-app **keyboard shortcuts** cheatsheet for common editor
and navigation bindings. Open it from the app’s help / shortcuts entry (often
via the command palette or Help menu, depending on platform).

## Onboarding

When you pick or open a vault, onboarding tips may appear for first-run flows.
Those tips are separate from the AI agent.

## Ask the agent

With **Enable AI** on, open **Silt AI** and ask how to use a feature. The
agent can search shipped product help (this corpus) for setup and how-to
answers. For questions about *your* notes, it searches the vault instead.
