## Shortcut cheatsheet

Open **Keyboard shortcuts** any of these ways:

- Press **Shift+?** (default hotkey `open_shortcuts_help`)
- Type **`/`** in the editor and choose **Keyboard shortcuts**
- Use the app Help / shortcuts entry when available

The cheatsheet lists live bindings from your vault hotkeys (Settings →
Hotkeys), including editor formatting and table row/column insert shortcuts
when configured.

## Common editor shortcuts

Exact chords depend on your hotkey config. Defaults often include:

| Action | Typical default |
| --- | --- |
| Bold / Italic / Underline | Ctrl+B / Ctrl+I / Ctrl+U |
| Open shortcuts help | Shift+? |
| Toggle format toolbar | Ctrl+F1 |
| Table insert row above/below | Ctrl+Shift+Up / Down |
| Table insert column left/right | Ctrl+Shift+Left / Right |

## Slash commands

Type **`/`** in the editor for headings, tasks, **tables**, callouts, code,
templates, and more. See product help topics **Slash commands** and
**Tables**.

## Onboarding

When you pick or open a vault, onboarding tips may appear for first-run
flows. Those tips are separate from the AI agent.

## Ask the agent

With **Enable AI** on, open **Silt AI** and ask how to use a feature. The
agent searches shipped product help for setup and how-to answers (including
slash commands and tables). For questions about *your* notes, it searches
the vault instead.
