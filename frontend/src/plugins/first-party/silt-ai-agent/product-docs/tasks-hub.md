## Open the Tasks hub

Click **Tasks** (checklist icon) on the left **activity bar**. One hub shows
the same task set in three modes — switch with the header control labeled
**Tasks display mode**:

| Mode | Best for |
| --- | --- |
| **List** | Time horizons (Overdue, Today, Upcoming, Later, No Date, Completed) |
| **Board** | Status columns with drag-and-drop (default TODO / DOING / DONE) |
| **Calendar** | Month/week layout by start or due date |

## Create a task

- **Global quick-add:** default **Ctrl+Shift+N** (**New task**) — overlay to
  capture a task fast (often undated).
- **In the hub:** footers on List, Board column **+**, or a Calendar day cell.
- **In a note:** slash **Task**, or a GFM checkbox line `- [ ] …`.

Standalone quick-add tasks (not on a normal page) live in a hidden system file
and only appear in the **Tasks** hub — not as a normal notebook page.

## Organize the view

- **Group by:** None, Status, Owner, Priority, Due date, Tag, Notebook,
  Section, Page.
- **Sort within group:** Manual, Due, Priority, Title, Created, Owner,
  Recently Modified, Estimate.
- **Hub command palette:** default **Ctrl+K** when Tasks is focused (and the
  editor is not) — switch mode/group/sort, jump to saved views, find/add task.

While Tasks is open, the sidebar can show **Smart lists** (Today, Upcoming,
Overdue, Completed, All Tasks), **Saved views**, and a mini-calendar.

## Saved views

Bookmark the current mode, grouping, sort, filters, and columns as a named
**saved view**. Built-in system views (read-only) include **Today’s Board**,
**By Owner**, and **This Week’s Calendar**.

## Edit a task

Click a row or card to open the task edit drawer (status, due, priority, owner,
tags, comments, and more). Sub-task progress can show as done/total on cards.

## Tips

- Undated quick-add tasks land naturally under List → **No Date**.
- Opening Tasks from the activity bar starts vault-wide (not locked to one page).
- With AI on, the agent can query or update tasks subject to **Agent vault writes**.
