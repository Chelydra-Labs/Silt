# Silt UI Baseline Audit Matrix (#1073)

This document records the baseline visual and structural audit across every Silt view, settings section, and global overlay using the dev-only browser visual-audit harness (`?harness=1` or `VITE_AUDIT_HARNESS=1`), together with the resolution delivered across GitHub Milestone #70 (#1073–#1080).

## How to Launch the Audit Harness

Start the frontend Vite server in standalone dev mode:

```bash
cd frontend
npm run dev
```

Open any deep-link URL below against `http://127.0.0.1:9245/`. Combine `view`, `state` (`default | loading | empty | error`), `tab`, `dialog`, and `tag` query parameters to inspect target states without launching the Go/Wails backend.

## 4. Cross-Cutting Consolidation Roadmap (#1074–#1080)

1. **#1074 — Shared UI Primitives (`Button`, `IconButton`, `Input`, `Dialog`):** **Completed in PR #1084**. Created token-only `frontend/src/components/ui/{Button,IconButton,Input,Dialog}.svelte` following ADR 0009 (`role="dialog"`/`"alertdialog"`, `aria-modal="true"`, `bg-black/45 backdrop-blur-[2px]`, `trapFocus`, Escape, opener focus return) and migrated `ConfirmDialog`, `ChoiceDialog`, and `NamePromptDialog`.
2. **#1075 — App Shell, `ViewHeader` & Sidebar Navigation:** **Completed in PR #1085**. Created `frontend/src/components/ui/ViewHeader.svelte` and aligned full-pane workspace headers (`TypeDashboard`, `TagsExplorer`, `SettingsPanel`, `TasksHub`) and `PageBreadcrumb`; fixed `SidebarNavTree.svelte` notebook dropdown `Escape`/focus-return and keyboard context-menu `anchorEl`; auto-collapses/overlays sidebar at narrow widths (`≤700px`).
3. **#1076 — Editor Chrome & Formatting Surfaces:** **Completed in PR #1086**. Replaced hardcoded chrome `font-size:` declarations and ad-hoc input styles in `TipTapEditor.svelte` and `frontend/src/components/editor/*` (`FormatToolbar`, `FindBar`, `EditorUtilityBar`, `SelectionBubble`, `HeadingLevelMenu`, `ColorPickerMenu`, `TableSizePicker`, `SuggestPopup`, `EditorContextMenu`, `FormattingFirstRunTip`, `PluginNoteBanners`) with `--text-type-*` and `--text-icon-*` tokens.
4. **#1077 — Settings Overhaul (All 9 Tabs):** **Completed in PR #1087**. Fixed `h2 → h4` heading-level skips in `EditorTab`, `HotkeysTab`, and `DevTab` so all 9 tabs use `<h3>` under `SettingsPanel.svelte`'s `<h2>`; standardized section cards (`bg-surface-panel border border-surface-panel-border rounded-lg p-4`); added inline `aria-invalid`/`aria-describedby` validation to `EditorTab` numeric fields and `GeneralTab` custom dictionary add.
5. **#1078 — Tasks Hub, Type Dashboard, Tags Explorer & Backlinks:** **Completed in PR #1088**. Extracted `frontend/src/components/ui/ViewState.svelte` and adopted it across `TypeDashboard`, `TagsExplorer` (adding user-facing `role="alert"` error + retry for failed tag IPC), `TasksHub` (`ListView`, `BoardView`, `CalendarView`), and compact `BacklinksSidebarPanel` states; fixed `min-w-[43.75rem]` narrow-window overflow in `CalendarView.svelte`.
6. **#1079 — Dialogs, Menus, Command Surfaces & `svelte-ignore` Audit:** **Completed in PR #1089**. Converged `SearchModal`, `QuickSwitcher`, `ShortcutHelp`, `TemplatePicker`, `GlobalReplaceModal`, `PageHistoryModal`, `DeletedPageHistoryModal`, `TaskSubEditorModal`, `PluginModalHost`, `ModalShell`, and `App.svelte` QuickAdd on `Dialog.svelte`; adopted compact `ViewState` for empty `SearchModal`/`QuickSwitcher` results; audited and reduced `svelte-ignore a11y` suppressions to ≤12 with full justification.
7. **#1080 — Onboarding, Toasts & Cross-Page A11y Polish:** **Completed in PR #1090**. Replaced `window.alert` in `App.svelte` with inline `role="alert"` error banner + retry in `Onboarding.svelte`, fixed `.onboarding-btn` UI typography/focus ring/390px single-line fit and WCAG AA body copy contrast, added `viewGeneration` stale-toast clearing and guarded `Escape` dismissal to `ToastContainer.svelte`, and completed `GeneralTab` menu focus-return polish.
