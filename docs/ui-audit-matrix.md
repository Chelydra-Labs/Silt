# Silt UI Baseline Audit Matrix (#1073)

This document records the baseline visual and structural audit across every Silt view, settings section, and global overlay using the dev-only browser visual-audit harness (`?harness=1` or `VITE_AUDIT_HARNESS=1`).

## How to Launch the Audit Harness

Start the frontend Vite server in standalone dev mode:

```bash
cd frontend
npm run dev
```

Open any deep-link URL below against `http://127.0.0.1:9245/`. Combine `view`, `state` (`default | loading | empty | error`), `tab`, `dialog`, and `tag` query parameters to inspect target states without launching the Go/Wails backend.

## 4. Cross-Cutting Consolidation Roadmap (#1074–#1080)

1. **#1074 — Shared UI Primitives (`Button`, `IconButton`, `Input`, `Dialog`):** Create token-only `frontend/src/components/ui/{Button,IconButton,Input,Dialog}.svelte` following ADR 0009 (overlay `<div>` with `role="dialog"`/`"alertdialog"`, `aria-modal="true"`, `bg-black/45 backdrop-blur-[2px]`, `trapFocus`, Escape, opener focus return) and migrate `ConfirmDialog`, `ChoiceDialog`, and `NamePromptDialog`.
2. **#1075 — App Shell, `ViewHeader` & Sidebar Navigation:** Create `frontend/src/components/ui/ViewHeader.svelte` and align full-pane workspace headers (`TypeDashboard`, `TagsExplorer`, `SettingsPanel`, `TasksHub`) and `PageBreadcrumb`; fix `SidebarNavTree.svelte` notebook dropdown `Escape`/focus-return and keyboard context-menu `anchorEl`; auto-collapse/overlay the sidebar at narrow widths (`≤700px`).
3. **#1076 — Editor Chrome & Formatting Surfaces:** Replace hardcoded chrome `font-size:` declarations and ad-hoc input styles in `TipTapEditor.svelte` and `frontend/src/components/editor/*` (`FormatToolbar`, `FindBar`, `EditorUtilityBar`, `SelectionBubble`, `HeadingLevelMenu`, `ColorPickerMenu`, `TableSizePicker`, `SuggestPopup`, `EditorContextMenu`, `FormattingFirstRunTip`, `PluginNoteBanners`) with `--text-type-*` and `--text-icon-*` tokens while preserving document/math content typography.
4. **#1077 — Settings Overhaul (All 9 Tabs):** Fix `h2 → h4` heading-level skips in `EditorTab`, `HotkeysTab`, and `DevTab` so all 9 tabs use `<h3>` under `SettingsPanel.svelte`'s `<h2>`; standardize section cards (`bg-surface-panel border border-surface-panel-border rounded-lg p-4`); and add inline `aria-invalid`/`aria-describedby` validation to `EditorTab` numeric fields and `GeneralTab` custom dictionary add.
5. **#1078 — Tasks Hub, Type Dashboard, Tags Explorer & Backlinks:** Extract `frontend/src/components/ui/ViewState.svelte` from `TypeDashboard.svelte:644` and adopt it across `TypeDashboard`, `TagsExplorer` (adding user-facing `role="alert"` error + retry for failed tag IPC), `TasksHub` (`ListView`, `BoardView`, `CalendarView`), and compact `BacklinksSidebarPanel` states; fix `min-w-[43.75rem]` narrow-window overflow in `CalendarView.svelte:887,912,1092`.
6. **#1079 — Dialogs, Menus, Command Surfaces & `svelte-ignore` Audit:** Converge `SearchModal`, `QuickSwitcher`, `ShortcutHelp`, `TemplatePicker`, `GlobalReplaceModal`, `PageHistoryModal`, `DeletedPageHistoryModal`, `TaskSubEditorModal`, `PluginModalHost`, `ModalShell`, and `App.svelte` QuickAdd on `Dialog.svelte`; adopt compact `ViewState` for empty `SearchModal`/`QuickSwitcher` results; and audit/reduce all 15 `svelte-ignore a11y` suppressions (`EditorContextMenu.svelte:221–222`, `TipTapEditor.svelte:1415`, etc.).
7. **#1080 — Onboarding, Toasts & Cross-Page A11y Polish:** Replace `window.alert` in `App.svelte:780` with inline `role="alert"` error + retry in `Onboarding.svelte`, fix `.onboarding-btn` UI typography/focus ring/390px single-line fit, add `viewGeneration` stale-toast clearing and guarded `Escape` dismissal to `ToastContainer.svelte`, and complete `GeneralTab` menu focus-return polish.
