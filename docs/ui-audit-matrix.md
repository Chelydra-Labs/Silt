# Silt UI Baseline Audit Matrix (#1073)

This document records the baseline visual and structural audit across every Silt view, settings section, and global overlay using the dev-only browser visual-audit harness (`?harness=1` or `VITE_AUDIT_HARNESS=1`).

## How to Launch the Audit Harness

Start the frontend Vite server in standalone dev mode:

```bash
cd frontend
npm run dev
```

Open any deep-link URL below against `http://127.0.0.1:9245/`. Combine `view`, `state` (`default | loading | empty | error`), `tab`, `dialog`, and `tag` query parameters to inspect target states without launching the Go/Wails backend.

## 4. Cross-Cutting Consolidation Roadmap (#1074–#1080)

1. **#1074 — Shared `PageHeader` & `EmptyState` Primitives:** Unify header padding/typography (`TagsExplorer`, `TypeDashboard`, `TasksHub`, `SettingsPanel`) and replace bespoke loading/empty/error blocks across `Onboarding`, `App.svelte` (empty notes), `TagsExplorer`, `TypeDashboard`, `TasksHub`, and `BacklinksSidebarPanel`.
2. **#1075 — Shared `ModalShell` & `MenuSurface` Primitives:** Deduplicate `ConfirmDialog`, `ChoiceDialog`, `NamePromptDialog`, `SearchModal`, `QuickSwitcher`, `ShortcutHelp`, `TemplatePicker`, and `GlobalReplaceModal` onto a single `ModalShell` (standard z-index, backdrop token, `trapFocus`, Escape, focus return), and standardize dropdown menus (`TasksHub` manage menu, `GeneralTab` vault menu, `ContextMenu`) on `MenuSurface`.
3. **#1076 — Shell, Sidebar, TitleBar, TabStrip & Backlinks Polish:** Normalize sidebar section headers, `BacklinksSidebarPanel` cards/badges, `TabStrip` active/dirty indicators, and `PageBreadcrumb` spacing.
4. **#1077 — Editor Chrome, Find/Replace, Properties Panel & Popovers:** Align `FormatToolbar`, `EditorUtilityBar`, `FindBar`, `PropertiesPanel`, and node-view popovers with shared surface/elevation tokens.
5. **#1078 — Data Views (`TagsExplorer`, `TypeDashboard`, `TasksHub` List/Board/Calendar):** Adopt `PageHeader`, `EmptyState`, and `MenuSurface`; unify filter bars, segmented view switchers, and card/table borders.
6. **#1079 — Settings Overhaul (All 9 Tabs):** Standardize settings card containers, form controls, status badges, and master-detail layouts across `General`, `Editor`, `Appearance`, `AI`, `Hotkeys`, `Templates`, `Plugins`, `Dev`, and `About`.
7. **#1080 — Theme Token & A11y Regression Guards:** Enforce token-only surface/modal/border rules in Vitest and verify zero a11y or contrast regressions across light and dark modes.
