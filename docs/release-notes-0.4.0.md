# Silt 0.4.0 — Typed Notes

Silt grows from a *graph of notes* into *databased notes*. A page can declare a
`type:` in its YAML frontmatter, inherit that type's typed-property schema, and
render/edit its properties through a dedicated UI and appear in a per-type
dashboard — with **Markdown frontmatter remaining the source of truth** and the
SQLite index reproducible from it.

## Highlights

- **Type schemas** live in `<vault>/.system/types/*.yaml`. Nine property types:
  `text`, `number`, `date`, `datetime`, `checkbox`, `select`, `multiselect`,
  `page` (single relation), `pages` (multi relation). Adding a property to a
  schema propagates to all instances virtually — existing files are not
  rewritten.
- **Properties surface** — an inline type chip + hero field in the breadcrumb
  row (untyped pages stay clean), and a bottom-docked properties panel
  (`Mod+;`) with per-field editors, optimistic commit, and a "Turn into" type
  conversion flow.
- **Per-type dashboards** — filter / sort / group by property, in Board and
  List views.
- **Typed relations** — `page`/`pages` fields link pages by type; deleted
  targets go silently inert (no back-write), consistent with backlinks.
- **Local MCP host** — three new tools: `get_page_metadata` (read, ungated),
  `set_page_property` and `set_page_type` (write-gated). Every write is
  schema-validated **before** any file I/O, so an invalid value never touches
  the file.

## One-time cache reset on first launch

0.4.0 triggers a one-time reset of the embedded WebView2 user-data directory on
first launch (`clearCacheOnVersionChange`). This is intentional: your notes,
settings, and vaults are unaffected — only the browser-engine cache clears.
Subsequent launches behave normally.

## Migration notes

- **Existing frontmatter is unchanged.** `type:` and property values are purely
  additive; pages without a `type:` look and behave exactly as before.
- The `.system/types/` folder is scaffolded automatically for new vaults and
  seeded with `book` and `meeting` example types. Existing vaults can create
  types from the type editor.
- Deleting the SQLite index (`index.sqlite*`) and relaunching rebuilds all
  type/property projections from frontmatter — the working-memory tier is fully
  reproducible.
